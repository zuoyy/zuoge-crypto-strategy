# neutral_probe 止损放大与止盈膨胀

## 问题

`_evaluate_context()` 中对 `neutral_probe` 阶段执行 `stop_pct × 1.5` 放大止损，但 TP 是按止损距离的倍数计算的。止损一宽，TP 等比放大，导致止盈目标不切实际。

## 计算链

```
1. 波动率代理: max(|24h变化|, |1h趋势|, 1.5)
2. 基础止损:   clamp(1.5% + vol/200, 1.5%, 7.5%)
3. neutral_probe: clamp(基础止损 × 1.5, 2.0%, 8.0%)   ← 放大 1.5x
4. TP1 = 止损 × 1.5, TP2 = 止损 × 2.2
```

## 影响

对于一个 24h 波动 7.5% 的币（典型 alt）：

| 参数 | 有 ×1.5 | 无 ×1.5 |
|------|---------|---------|
| 止损 | 7.875% | 5.25% |
| TP1 (平半仓) | 11.8% | 7.9% |
| TP2 (全平) | 17.3% | 11.6% |

有 ×1.5 时，做空需要币再跌 12-18% 才触达止盈——对 neutral_probe（弱信号）来说概率极低。

## 修复

2026-05-18：移除 neutral_probe 的 ×1.5 放大。公式 `clamp(stop_pct, 0.020, 0.080)`——保留 2% 地板和 8% 天花板，去掉乘法。

## 相关参数

| 阶段 | 止损倍率 | 说明 |
|------|---------|------|
| neutral_probe | ×1.0 | 基础止损，不放大 |
| deep_reversal | ×1.3 | 逆转阶段需要呼吸空间 |
| trend_continuation / early_trend | ×0.8 | 趋势跟踪可更紧 |
| 其他 | ×1.0 | 基础止损 |

## 教训

止损放大（给弱信号呼吸空间）的初衷是对的，但 TP 与止损挂钩会导致连锁放大。如果需要宽止损，应该同时考虑：
1. 降低 TP 倍率（如 TP1=1.0×止损 替代 1.5×）
2. 或者用独立公式计算 TP（与止损脱钩）
3. 或者不放大止损，靠入场精度控制风险
